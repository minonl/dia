# Security Policy

## Reporting

Please do not open a public issue for security problems.
Use GitHub's private vulnerability reporting for this repository; include reproduction,
affected version/commit, and impact.

## Scope

- The framework code and its packaging.
- Configuration examples and install scripts.
- Do not include credentials, customer data, or internal URLs in reports or examples.

## Supported versions

Only the latest `main` is supported until a release policy is published.
