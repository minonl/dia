# dia graph Web 视觉设计稿（v0.3）

> **落地状态（2026-11-06）**：M1 已实现 `dia graph --export-html`（真实账本 → 单文件静态 HTML，无网络）；
> 数据模型/契约/安全边界见 [graph-web-m1.md](graph-web-m1.md)。live 服务（M2）未做。

> 静态 mockup：[`graph-web-mockup.html`](graph-web-mockup.html)（浏览器直接打开，无网络/无依赖）
> 数据契约：`dia graph --json`（schema 1）；时间线所需 start/end 为后续扩展字段。

## 1. 两个视图

顶部 tab：

- **关系图**：回答“谁依赖谁、先后顺序、优先级”；
- **时间线**：独立甘特图，回答“什么时候做、做到哪、是否延期”。

### 关系图：按依赖深度分层，不按状态分列

- 纵轴 = 优先级，**P0 最高、P1 中间、P2 最下**；每个优先级是一条**通栏泳道色带**，泳道之间用虚线分隔，不再用闭合方框；
- P0/P1/P2 标签固定在左侧泳道栏、垂直居中；**横向滚动时标签吸住左边缘**（JS 同步 scrollLeft），泳道底色按级别计算（P0 最深，向下递减），可自然扩展 P3/P4；
- 组内从左到右 = 依赖顺序（按依赖深度排序）；
- **状态不占布局**：用内联图标/文本 + 进度条表达；
- `简约`：只显示 task + `depends_on`；
- `详细`：展开 owner、session、path、touches、claims，并在卡片里列具体关联（`depends_on / depended_by / touches / claims / collaborates_with`）。
- 图例固定在画布右下角：只显示当前模式会用到的边；`→` 单向、`↔` 双向，线型与图上一致。

### 时间线：独立甘特

- 每行一个 task，横轴为相对今天的天数（`-8d … today … +4d`）；
- 条长 = start/end，内部填充 = progress；
- 颜色 = status；橙色描边 = 关键路径；红色虚线 = 今天；
- 点击条/行可看任务详情。

## 2. 边语义

| 关系 | 方向 | 线型 | 颜色 |
|---|---|---|---|
| `depends_on` | 单向 `→` | 实线 | 蓝 |
| `touches` | 单向 `→` | 虚线 `6 4` | 紫 |
| `claims` | 单向 `→` | 点线 `2 3` | 青 |
| `collaborates_with` | 双向 `↔` | 点线 `1 3` + 双箭头 | 灰（视觉示例，未进 M1 契约） |

## 3. 为什么不再按状态列/行

状态列会把“关系”切碎，且 TODO/DONE、REVIEW/BLOCKED 混在一列没有语义。现在：

- 依赖顺序是主结构（拓扑层）；
- 状态是属性（颜色/进度）；
- 优先级是行分组（P0/P1/P2 各一行，最高在最上，虚线框圈组）；
- 时间放在独立时间线，不挤在关系图里。

## 4. 与数据契约的映射

| UI | 数据 |
|---|---|
| task 卡片 | `nodes[kind=task]` + status/owner |
| 依赖边 | `edges[kind=depends_on]` |
| touches / claims | `edges` 对应 kind |
| 进度 | 后续 `task.progress`（0-100） |
| 时间线 | 后续 `task.start/end`（相对/ISO） |
| 关键路径 | 后续由依赖图最长路径计算 |

## 7. URL 路由

静态稿支持 hash 路由（`file://` 直接可用）：

```
#/graph
#/graph?mode=simple
#/graph?mode=detail
#/timeline
```

- `view` 也可用 query 形式：`?view=timeline&mode=detail`；
- 切换 tab / 简约详细会同步更新 hash，便于分享/回链；
- 真正的独立 path（`/graph`、`/timeline`）需要部署层 rewrite 到同一 HTML，或导出时生成
  `graph.html` / `timeline.html`；静态文件本身不能凭空提供两个 path。

## 8. 颜色语义（v0.4）

原则：**颜色只表达警告/异常，正常状态去色**。

| 颜色 | 用途 | 不再用于 |
|---|---|---|
| 红 | blocked、P0、异常/失败 | 普通任务状态 |
| 橙 | review、claim 提醒、P1 | 完成态 |
| 蓝 | 只有“进行中”的进度条 | done/accepted/todo |
| 灰 | todo / done / accepted / P2 / 中性文本 | 警告/异常 |

- 优先级：P0 红实心；P1 橙描边；P2 灰描边（不抢眼）；
- 状态文本：只有 blocked / review 带颜色，其余中性；
- 进度条：doing 蓝色条纹动画；blocked 红色暂停/置灰；review 橙色；done/accepted 灰色静态；
- 时间线同一套语义；关键路径只用橙色描边。

## 9. 任务抽屉与介入（v0.5）

关系图里的卡片**全部是 task**，不再叫“节点详情”。

- 点击 task 卡片 → 右侧抽屉「任务详情」，两个 tab：
  - **任务**：status / priority / owner / progress / deps / 关联；
  - **介入**：通道切换 + 目标会话 + 输入框 + 发送（设计稿只演示）。
- 「需要人」每行带快速操作：
  - 阻塞 → `介入` / `查看`
  - claim → `联系持有者`
  - 待评审 → `开始评审`
- 介入通道明确区分：
  1. **TUI 会话**：选择 opencode / dsh 会话，输入后注入；
  2. **钉钉消息链**：选择群聊/私聊，输入后走钉钉；
  3. **dia msg**：选择 session id，走 dia 消息邮箱。
- 同一任务可以在抽屉里切换通道，方便“会话里没人就发钉钉 / 需要留痕就 dia msg”。
- 深链：`#/graph?task=t-4&tab=intervene` 可直接打开任务抽屉。

## 10. 规模样例（100 tasks / 30 天）

mockup 数据改为 **100 个任务、时间跨度 30 天**，用来验证真实规模下的布局：

- 关系图有两种布局：**优先级视图**（P0/P1/P2/P3 泳道）和**依赖视图**（按依赖深度从左到右）；
  两种视图**都不折叠任务**（没有 `+N 个` 聚合，任何卡片都能点开），靠时间窗 + 搜索 + 聚焦控制规模；
- mock 数据补齐跨优先级依赖，确保两种视图都能看到跨层关系；依赖边只连接当前可见任务；
- 卡片垂直基准分两种模式：**详细** = 进度条中心线（关系虚线/箭头也锚在进度条中心，同一行连线与进度条同高）；
  **简约** = 卡片盒整体垂直居中（连线锚在卡片盒中心）；两种模式都和泳道中心线/左侧级别标签对齐；
- 卡片偏移量按实际渲染测量（含字体加载后重排），不写死魔法数；泳道顶部/右侧空白按实际内容收紧。
- 时间线：按当前时间窗过滤后纵向滚动；轴显示绝对日期（`MM-DD`）并保留相对天数
  （`-7d / 今天 / +Nd`）。
- 泳道标签在**外层固定 rail**，不参与横向滚动；只随纵向 `scrollTop` 同步位置；
- 泳道标签为全宽色带 + 虚线分隔，P0/P1/P2/P3 由数据动态生成。
- 依赖视图按实测卡片高度逐列堆叠，`详细` 模式下卡片不会互相重叠；依赖视图没有泳道，左侧不留级别标签遮罩/占位；
- 关系视图参数：`#/graph?layout=dep`（依赖视图）/ 默认优先级视图；
- 时间窗参数（两个视图共用）：`#/graph?w=7|14|30|0`（0 = 全部）；时间线 `#/timeline?w=7`；
  显式区间：`#/timeline?from=2026-10-22&to=2026-11-21`。

## 10.1 规模控制：时间窗 + 搜索 + 聚焦

无折叠后，用三种手段控制一次看多少：

- **时间窗（默认近 7 天，按开始时间，结束时间不限）**：只显示 `start >= 今天 - N` 的任务，
  长任务即使结束在很久以后也照常显示；时间线轴自动从 `-N` 延伸到最晚的 `end`；
- **搜索即选择（token 输入框）**：聚焦就出下拉（列出当前时间窗全部任务，按优先级/开始时间排序），
  输入 ID / 名称 / owner 实时过滤；选中项**回显成 tag**（`t-003 ×`）留在输入框里，可多选；
  `↑↓` 选择、`Enter` 加入、`Esc` 收起、`Backspace` 删除最后一个 tag、点 `×` 删除单个；
  已选 tag 用蓝底高亮，下拉里带 `✓`；选择状态写进 URL（`sel=t-003,t-006`，向后兼容旧的 `focus=`）；
- **邻域聚焦（类 nx graph focus）**：选中任务后只保留这些任务的依赖邻域（多个取并集），
  深度可切 `1 层 / 2 层 / 全链路`，`清空` 回全量；双击卡片等同于点选该任务；
- 被过滤掉的任务不计入概览统计，标题显示 `显示 N / 总数`。

## 11. 时间线滚动与缩放

- 左侧任务列是**独立固定 pane**（不依赖 sticky），横向滚动时始终可见；任务名顶部对齐；
- 时间区右上角显示「← 左右滚动 →」提示，避免看不出可滚动；
- 右侧时间轴在 `tl-scroll` 内横向滚动，表头与内容同步；
- `zoom` = 每天像素宽度（默认 28，范围 **14–84**，即 50%–300%），控制条 `－ / 100% / ＋`，到边界禁用；
- URL：`#/timeline?w=7&zoom=40`；
- 任务纵向滚动，时间窗默认近 7 天开始（结束不限），绝对日期 + 相对天数同时显示。
