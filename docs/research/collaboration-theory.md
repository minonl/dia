# 人机协作与评估：理论依据（2026-10）

> 目的：给 dia 的 `(T, D, O)` 模型与指标找**可引用的理论出处**，并明确哪些是"有依据"、哪些是"我们拍的"。
> 结论先行：V 型与控制回路 / 类型×层级 / 抽象层级**对得上**；但 **Δ 阈值**和**自报深度**两处是直觉，不是理论。

## B. 站得住的三条

1. **顶端 = 意图**：Rasmussen 的抽象层级把目的置顶、形式置底，约束自上而下——"人守顶端"与其同构。
2. **深度做成矩阵**：Parasuraman 的 types×levels 明确四类功能各自定级；标量会掩盖"信息获取 9 级、决策 2 级"这类错配。
3. **Δ 是有效信号**：Lee & See 的校准需要"预期 vs 实际"偏差；Δ 是其代理。

## C. 站不住的四条（必须改）

1. **请示没有成本模型**：违反 Horvitz 的"错误成本/打断成本"。叠加 Bainbridge 1983（`10.1016/0005-1098(83)90046-8`）的 ironies——自动化越多，人越少练手，回给人的恰是最难的部分 → **请示风暴 + 顶端能力退化**。
2. **自报 + 同源复核 ≠ 校准**：自报是自信的代理，不是能力；同源复核对同源错误零功效（Skitka 1999 automation bias 同构）。**Δ≈0 无法区分"都对"与"共谋"**。
3. **按功能切 V 的两臂违反 JCS**：Hollnagel & Woods 要求分析单元是回路整体；按功能切会在交接处留下无人的失效地带。
4. **"人守顶端" ≠ 有意义的人类控制**：只做最终批准既不满足 tracking 也不满足 tracing；只记深度不记依据 = **名义控制**。

## D. 指标修正（按构念效度重写）

| 现指标 | 问题 | 配对/替代 |
|---|---|---|
| 观测覆盖率 | 多写事件即可刷高 | ＋**复核后仍成立的观测率**＋每千事件人工复核工时 |
| 深度达成 | 自报 ≠ 能力 | 改为 **calibration**：ECE / Brier（自报 vs 盲复核），报 ICC(2,k) |
| 部分产物复用 | activity 指标，奖励囤积 | ＋复用产物在下游的返工率/缺陷率（结果侧） |
| 压缩比 | 无操作定义 | 先定义"压缩信息量 vs token"，做不到就删 |
| 意图漂移 | 缺可判定 rubric | 双人独立盲标 + kappa ≥0.61（Landis & Koch 1977） |
| 请示质量 | 无结果侧 | ＝改变决策的比例 × 节省的错误成本 |
| 共谋信号 | 单一来源自指 | 第三方盲评；且**不得**进个人考核（Campbell 定律） |

**三问闸门**（Jacobs & Wallach）：构念被操作化了吗？有效度证据吗？对谁有效？

## E. 可执行规则（替代原来的直觉规则）

1. **撤回"Δ>0.3 必须先对齐"**：无出处。改为**成本加权**：`优先级 = Δ × 该判定的错误成本`，阈值**预注册**。
2. 请示三件套：不确定性 / 候选及代价 / 推荐项（Horvitz）。
3. **打断预算**：每人每时段上限，超限降级为异步队列（注意力成本）。
4. 顶端只保留三类决策：目标选择、冲突裁决、异常接管（Rasmussen + 监督控制）。
5. 深度按**四类功能**分别记录，**禁止**输出单一深度分（Parasuraman 2000）。
6. 复核必须**盲**且**异源**（automation bias / 独立性）。
7. 每 N 次自报抽 5% 盲复核，公开 ECE（校准）。
8. 每个观测事件必带 provenance：`intent_id / judge_id / upstream_artifact_ids`（MHC tracing）。
9. 自动化升级时同步提高人的手动演练配额（Bainbridge / OOTL）。
10. 指标上线前须有构念定义 + 反例测试；指标不得进个人考核（Cronbach & Meehl；Goodhart/Campbell）。
11. 子 agent 不得自签验收——**弱支持**（Klein directability 只提供类比）。

## G. 对 dia 的两条硬结论

1. **先加 provenance，再加深度**：没有 `intent_id / judge_id / upstream` 的观测，不满足 tracing，深度再准也是名义控制。
2. **先把"共谋"做成可判**：盲复核 + 第三方抽检；否则 Δ 小只会被误读成"对齐良好"。
